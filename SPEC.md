# ТЗ: AI-репетитор в Telegram с подпиской за Stars

## Цель
Ученик присылает фото или текст задачи — бот решает её по шагам и объясняет решение.
Бесплатно N решений в месяц, дальше — подписка за Telegram Stars.

Два назначения:
1. Реальный продукт, который можно запустить и зарабатывать.
2. Кейс для портфолио Upwork: AI + распознавание фото + Telegram + подписки + лимиты + контроль расходов на LLM.

## Пользовательский сценарий
1. `/start` — приветствие, что умеет бот, сколько бесплатных решений осталось.
2. Ученик отправляет фото задачи (или текст, или фото с подписью).
3. Бот показывает «печатает…», затем присылает решение:
   - условие задачи, как бот его понял (чтобы ученик видел, если фото распознано неверно);
   - решение по шагам с объяснением каждого шага;
   - ответ отдельной строкой.
4. Под решением кнопки: «Не понял, объясни проще», «Проверь мой ответ», «Новая задача».
5. Уточняющие вопросы по той же задаче не тратят лимит (до 5 на задачу).
6. Когда бесплатные решения кончились — сообщение с предложением подписки и кнопкой оплаты.

## Функции (MVP)

### 1. Решение задач (ядро)
- Вход: фото (одно на задачу), текст, фото + подпись.
- LLM с поддержкой изображений (Claude, Anthropic SDK). Модель задаётся в `.env`.
- Предметы: математика, физика, химия, русский и английский язык — школьная программа.
- Язык ответа = язык пользователя (RU / EN по `language_code` в Telegram, с ручным переключением `/lang`).
- Если на фото не задача или фото нечитаемо — вежливо просит переснять, лимит не списывается.
- Формулы — обычным текстом / Unicode (x², √, ≤), без LaTeX. Разметка — Telegram HTML.
- Длинный ответ разбивается на несколько сообщений (лимит Telegram 4096 символов).

### 2. Лимиты
- Бесплатно: `FREE_SOLUTIONS_PER_MONTH` (по умолчанию 15) за календарный месяц.
- Решение списывается только после успешного ответа LLM.
- Подписчики: без лимита, но с защитным потолком `PAID_SOLUTIONS_CAP` в месяц (по умолчанию 300) — чтобы расходы на LLM не ушли в минус.
- Антиспам: не больше 1 запроса одновременно на пользователя, rate limit на частоту.

### 3. Подписка за Telegram Stars
- Валюта `XTR`, подписка на 30 дней через `createInvoiceLink` с `subscription_period`.
- Цена — `SUBSCRIPTION_PRICE_STARS` в `.env`.
- Обработка `pre_checkout_query` и `successful_payment`.
- Начисление идемпотентно: по `telegram_payment_charge_id`, повторное событие не продлевает подписку дважды.
- Продление и отмена подписки отражаются в статусе пользователя.
- Обязательные для платёжных ботов команды: `/terms` (условия) и `/paysupport` (поддержка по оплате).

### 4. Учёт расходов
- Для каждого решения сохраняется: модель, input/output токены, стоимость в $.
- Это нужно и для админ-статистики, и как аргумент для клиентов («контроль стоимости LLM»).

### 5. Админка в Telegram
Команды доступны только ID из `ADMIN_IDS`:
- `/stats` — пользователи (всего / активные за 7 дней), решения сегодня / за месяц, подписчики, выручка в Stars, расходы на LLM в $.
- `/grant <user_id> <days>` — выдать подписку вручную.
- `/refund <charge_id>` — вернуть Stars (`refundStarPayment`).

## Не делаем (вне MVP)
Веб-админка, несколько фото на задачу, рендер формул в картинки, реферальная программа, история решений в виде архива.

## Нефункциональные требования
- Python 3.12, uv, aiogram 3, PostgreSQL (SQLAlchemy async + Alembic), Redis (FSM, rate limit).
- Запуск одной командой: `docker compose up`. Режим: long polling.
- Секреты только в `.env`, есть `.env.example`.
- Тесты (pytest): лимиты и их сброс по месяцам, идемпотентность платежей, разбиение длинных сообщений, расчёт стоимости. LLM и Telegram в тестах мокаются.
- Логи в JSON, ошибки LLM и Telegram не роняют бота: пользователь получает понятное сообщение, лимит не списывается.
- README на английском: что это, GIF/скриншоты, архитектура, как запустить.

## Этапы и критерии готовности

| # | Этап | Готово, когда |
|---|------|---------------|
| 1 | Каркас: uv, aiogram, Postgres, Redis, Alembic, docker compose | `docker compose up`, бот отвечает на `/start` |
| 2 | Ядро: решение задачи по фото и тексту | на фото задачи приходит решение по шагам |
| 3 | Диалог по задаче: кнопки, уточнения, RU/EN | «Объясни проще» и «Проверь мой ответ» работают в контексте задачи |
| 4 | Лимиты + учёт расходов | после N решений бот предлагает подписку; токены и $ пишутся в БД |
| 5 | Подписка за Stars | оплата проходит, лимит снимается, повторное событие не дублирует продление |
| 6 | Админ-команды | `/stats`, `/grant`, `/refund` работают |
| 7 | Деплой + README + видео | бот работает на VPS, README и видео на 1 минуту готовы |
